# 儿童牙科候诊玩具消毒与轮换系统

管理候诊玩具从清洁库投放到候诊区、回收、按材质清洁消毒、规定干燥后重新投放的完整周转，
并覆盖破损隔离与护士长复核。**不保存任何真实患儿信息**，仅登记玩具与周转事件。

## 一条命令启动

```bash
python3 -m toyrotation
```

默认访问 http://127.0.0.1:8000 。启动时会自动：

1. 重建 SQLite 数据库（`data/toyrotation.db`）；
2. 生成演示样例：**材质冲突**（木质误入机洗批次被拒并登记）、
   **批量隔离**（设备回执消毒失败 → 整批隔离）、**维修样例**（掉件送修、补件完成待复核），
   以及回收漏扫、玩具错区、锐边隔离等；
3. 在本地目录生成破损照片占位图（`data/photos/`）；
4. 启动进程内守护任务，每 2 秒计算干燥完成与轮换时点。

常用参数：

```bash
python3 -m toyrotation --port 8000 --minute-seconds 10   # 默认：1 规定分钟=10 秒，便于演示
python3 -m toyrotation --minute-seconds 60 --no-reset    # 真实时长并保留数据
```

## 周转工序与规则

```
清洁库 ──投放──▶ 候诊区 ──回收扫描──▶ 回收箱(待清洁) ──加入材质批次──▶ 清洁/消毒
                                                                      │
            重新投放 ◀── 到时自动回库 ◀── 干燥(规定时长) ◀── 消毒达标(设备回执)◀┘

任意环节发现 锐边 / 掉件 / 污染风险 ──▶ 立即隔离（锁）  ──维修/重新清洁/报废──▶ 仅护士长复核解除
```

- **唯一区域**：同一玩具同一时刻只在一个区域；
- **投放排他**：投放使用 `BEGIN IMMEDIATE` 立即事务，两名员工并发投放仅一人成功；
- **工序阻断**：未消毒不能干燥、未到干燥时间不能回库投放（登记“干燥提前”）；
- **材质兼容**：木质只可擦拭、布艺只可机洗、金属不可浸泡；不兼容登记并拒绝；
- **隔离锁定**：普通清洁不能解除隔离；锐边/污染须先维修，掉件须补齐零件；
  护士长可处置为合格回库 / 重新清洁 / 报废；
- **前台只读**：只能看到各候诊区可用数量、容量与下次轮换时间，无玩具明细。

## 登记的异常类型（incidents）

| 类型 | 触发点 |
|---|---|
| 玩具错区 `wrong_area` | 回收扫描时实物区域与登记区域不一致 |
| 回收漏扫 `missed_scan` | 巡检发现漏扫或超过轮换时点未回收 |
| 材质不兼容 `material_incompat` | 按材质不允许的方式清洁（拒绝且留痕） |
| 消毒失败 `disinfect_failed` | 模拟设备回执温度/时长不达标 |
| 干燥提前 `dry_early` | 未到规定干燥时长试图取用/投放（拒绝且留痕） |
| 零件缺失 `part_missing` | 掉件导致零件数不足，立即隔离 |
| 批量隔离 `batch_isolation` | 消毒失败等批次风险，整批锁定 |

## 页面（九个视图）

候诊区、区域投放表、玩具库（小图标+编号密集网格）、回收扫描、消毒组批（突出材质分组、
设备回执）、干燥计时（进度与倒计时，可验证提前取用被拒）、破损处理（照片存本地）、
隔离复核（锁形图标+文字，护士长操作）、追溯与异常（按玩具/批次查 SQLite 事件链）。

配色为洁净白、海盐蓝、柔和珊瑚，无卡通背景。可在右上角切换三种角色体验权限差异。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：8 线程并发投放恰好一人成功、跨区域唯一性、工序阻断、干燥边界（差 1 秒拒绝）、
材质冲突登记、隔离权限（员工/前台/护士长）、消毒失败整批隔离、按玩具/批次的事件追溯，
以及 HTTP 层并发与前台数据裁剪（共 24 项）。

## 代码结构

```
toyrotation/
  models.py     # 区域/状态/材质/清洁方式/角色/事件与异常常量
  db.py         # SQLite 表结构与事件/异常写入
  adapters.py   # 消毒设备模拟适配器（可预置失败，返回设备回执）
  service.py    # 核心业务规则（排他、阻断、批次、干燥、隔离复核）
  scheduler.py  # 进程内任务：干燥完成与轮换时点
  seed.py       # 一条命令所需的材质冲突/批量隔离/维修等样例
  app.py        # http.server JSON API，Cookie 角色与权限校验
  static/       # index.html / app.css / app.js
tests/
  test_service.py  test_web.py
```
